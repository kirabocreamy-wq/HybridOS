# Contributing to HybridOS

Thank you for considering contributing to the HybridOS project! We welcome contributions in various forms: code, documentation, and design.

## Code Style
- Follow the project's coding standards as defined in the [Coding Guidelines](link-to-guidelines).
- Use consistent formatting, including naming conventions and indentation (spaces/tabs).

## Commit Format
- Use the following format for commit messages:
  
  `type: subject`
  
- Types: `feat` (new feature), `fix` (bug fix), `docs` (documentation changes), `style` (formatting changes), `refactor` (code changes that don't fix bugs or add features), `perf` (performance improvements), `test` (adding tests).

- Each message should be concise yet descriptive, providing enough context for reviewers.

## Pull Request Process
1. Fork the repository and create a new branch for your feature or bug fix.
2. Ensure that your code passes all tests and adheres to code style guidelines.
3. Submit a pull request describing your changes and linking to any relevant issues.
4. Be responsive to reviews and make required changes in a timely manner.

## Development Setup
1. **Clone the repository:**  
   `git clone https://github.com/<your-username>/HybridOS.git`
2. **Install dependencies:**  
   Follow the instructions in the [Setup Guide](link-to-setup-guide).
3. **Run the application:**  
   Use the command provided for starting the application in a development environment.

## Areas for Contribution
- Bug fixes and enhancements
- Documentation improvements
- New features and functionality
- Testing and QA

Thank you for your contributions! Together we can make HybridOS better!
